# 🚀 Flask DevOps Docker Project

A simple DevOps project demonstrating how to containerize a Flask web application using Docker and manage it using Git & GitHub.

---

## 📌 Project Overview

This project is a basic **Flask web application** that returns a simple message:

> "Hello DevOps! App is running 🚀"

The application is containerized using **Docker** to ensure consistency across different environments.

---

## 🛠️ Tech Stack

- Python 🐍
- Flask 🌐
- Docker 🐳
- Git & GitHub 🔧
